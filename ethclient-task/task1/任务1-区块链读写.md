# 任务 1：区块链读写

## 任务目标

使用 **Sepolia 测试网络** 实现基础的区块链交互，包括：

- **查询区块**：按区块号获取区块信息（哈希、时间戳、交易数量等）
- **发送交易**：构造、签名并发送一笔简单的 ETH 转账，获取交易哈希

---

## 一、环境搭建

### 1.1 安装开发工具

| 工具 | 说明 | 安装/获取方式 |
|------|------|----------------|
| **Go 语言** | 开发环境，建议 1.18+ | [https://go.dev/dl/](https://go.dev/dl/) |
| **go-ethereum** | 以太坊 Go 客户端库（ethclient） | `go get github.com/ethereum/go-ethereum` |

**验证 Go 环境：**

```bash
go version
```

**在项目中引入 go-ethereum：**

```bash
cd your-project-dir
go mod init your-module-name   # 若已有 go.mod 可跳过
go get github.com/ethereum/go-ethereum
```

### 1.2 注册 Infura 并获取 Sepolia API Key

1. 打开 [https://infura.io](https://infura.io)，注册账户。
2. 登录后进入 Dashboard，创建项目（Create New Key → Web3 API）。
3. 在项目设置中复制 **Project ID**（即 API Key）。
4. Sepolia 测试网 RPC 地址格式为：  
   `https://sepolia.infura.io/v3/<YOUR_PROJECT_ID>`

**安全提示：** 不要将 API Key 提交到版本库，建议使用环境变量：

```bash
export INFURA_API_KEY=your_project_id_here
```

## 二、查询区块

### 2.1 目标

- 使用 **ethclient** 连接到 Sepolia 测试网。
- 查询**指定区块号**的区块信息。
- 输出到控制台：**区块哈希、时间戳、交易数量** 等。

### 2.2 实现要点

1. **连接节点**
   - 使用 `ethclient.Dial("https://sepolia.infura.io/v3/" + apiKey)` 连接 Sepolia。
   - API Key 从环境变量 `INFURA_API_KEY` 读取。

2. **查询指定区块**
   - 使用 `client.BlockByNumber(ctx, blockNumber)`。
   - `blockNumber` 为 `*big.Int`，例如 `big.NewInt(区块号)`。

3. **从区块中获取**
   - **区块哈希**：`block.Hash().Hex()`
   - **时间戳**：`block.Time()`（Unix 秒），可用 `time.Unix(block.Time(), 0)` 转为可读时间。
   - **交易数量**：`len(block.Transactions())`
   - 还可输出：区块号、父区块哈希、Gas 使用等。

4. **输出**
   - 将上述信息格式化打印到控制台。

### 2.3 示例输出格式

```
=== 区块信息 (Sepolia) ===
区块号: 12345678
区块哈希: 0x...
父区块哈希: 0x...
时间戳: 2025-02-10 12:00:00 UTC
交易数量: 42
...
```

### 2.4 参考代码结构

```go
// 连接
client, err := ethclient.Dial("https://sepolia.infura.io/v3/" + os.Getenv("INFURA_API_KEY"))
// 查询指定区块，例如区块号 6000000
block, err := client.BlockByNumber(context.Background(), big.NewInt(6000000))
// 使用 block.Hash(), block.Time(), block.Transactions() 等输出信息
```

## 三、发送交易

### 3.1 目标

- 准备一个 **Sepolia 测试网账户**，并获取其**私钥**。
- 使用 ethclient 连接 Sepolia。
- **构造**一笔简单的**以太币转账**（指定发送方、接收方、金额）。
- **签名**并**发送**交易到网络。
- 在控制台**输出交易哈希**。

### 3.2 准备账户与测试币

1. **账户**
   - 使用已有钱包（如 MetaMask）导出私钥，或使用本仓库 2.04 创建钱包模块生成新账户。
   - 私钥需妥善保管，仅用于测试网时可放在环境变量中：  
     `export PRIVATE_KEY=你的十六进制私钥`

2. **Sepolia 测试币**
   - 从水龙头获取，例如：
     - [https://sepoliafaucet.com](https://sepoliafaucet.com)
     - [https://www.alchemy.com/faucets/ethereum-sepolia](https://www.alchemy.com/faucets/ethereum-sepolia)

### 3.3 实现要点

1. **连接**
   - 同样使用 `ethclient.Dial("https://sepolia.infura.io/v3/" + apiKey)` 连接 Sepolia。

2. **加载私钥**
   - 从环境变量读取 `PRIVATE_KEY`（可去掉前缀 `0x`）。
   - 使用 `crypto.HexToECDSA(privateKeyHex)` 得到 `*ecdsa.PrivateKey`。
   - 发送方地址：`crypto.PubkeyToAddress(privateKey.PublicKey)`。

3. **构造转账交易**
   - **To**：接收方地址（`common.HexToAddress(toAddressHex)`）。
   - **Value**：转账金额，单位 Wei（1 ETH = 10^18 Wei），可用 `big.NewInt()` 或自定义函数换算。
   - **GasLimit**：例如 `21000`（简单 ETH 转账）。
   - **GasPrice** 或 **GasFeeCap**：可通过 `client.SuggestGasPrice(ctx)` 或链上建议值获取。

4. **Nonce**
   - 使用 `client.PendingNonceAt(ctx, fromAddress)` 获取当前账户的待处理 Nonce。

5. **签名与发送**
   - 使用 `types.SignTx()` 或 `types.NewTx()` + 签名，链 ID 使用 Sepolia：11155111。
   - 使用 `client.SendTransaction(ctx, signedTx)` 发送。
   - 交易哈希：`signedTx.Hash().Hex()`，输出到控制台。

### 3.4 环境变量示例

```bash
export INFURA_API_KEY=your_infura_project_id
export PRIVATE_KEY=你的私钥十六进制
export TO_ADDRESS=0x接收方地址
```

### 3.5 示例输出格式

```
=== 发送 ETH 转账 (Sepolia) ===
发送方: 0x...
接收方: 0x...
金额: 0.001 ETH
交易哈希: 0x...
```
